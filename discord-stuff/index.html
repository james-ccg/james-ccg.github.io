Discord Channel Renamer

Rename a lot of channels at once: paste the channel list, edit the names, and copy back only the ones you changed.

  1. Paste the exported channel list into the first box and press Parse. It's a JSON array of channels, each an id and a name - put ! in front of a text channel's id: 
    [{"i":"!123456789","n":"general"},{"i":"987654321","n":"Voice Lounge"}]
  2. Edit names in the Channels list. Text-channel names turn spaces into dashes as you type, the way Discord does; a changed channel is ticked for you.
  3. Press Generate and copy the result: only the ticked channels, with their new names.
